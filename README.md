# Aura Lumina

# AURA BRAND VISUAL IDENTITY — CRITICAL

The uploaded AURA logo is the definitive source of truth for the visual identity.

DO NOT introduce unrelated accent colors.

The entire website and application must derive its visual language from the logo:

BLACK + CHROME + SILVER + WHITE.

The logo has a futuristic luxury-metal aesthetic:

- deep black background

- polished chrome

- metallic silver

- bright white highlights

- dark gunmetal shadows

- reflective surfaces

- high contrast

- sophisticated monochrome palette

The website must feel like the digital extension of this exact logo.

==================================================

CHROME / METALLIC DESIGN LANGUAGE

==================================================

The most distinctive visual element of AURA should be its metallic chrome language.

Use metallic gradients carefully on:

- logo treatments

- major headings

- selected icons

- premium CTA buttons

- progress indicators

- verified skill states

- certification visuals

- decorative lines

- selected UI highlights

Chrome should NOT be used everywhere.

It should feel rare and premium.

Create subtle metallic gradients using grayscale tones:

bright silver → white → mid silver → gunmetal → dark silver

Avoid fake-looking rainbow metallic gradients.

The effect should resemble polished brushed chrome.

==================================================

TYPOGRAPHY

==================================================

Use a premium modern grotesk for UI:

Geist

Inter

Satoshi

or Manrope

For major editorial headlines, consider a sophisticated high-contrast serif or elegant display font only where appropriate.

The combination should feel like:

LUXURY FASHION

+

FUTURISTIC TECHNOLOGY

+

PRECISION CRAFT

Large headlines should be extremely confident.

Examples:

AURA

THE OPERATING SYSTEM

FOR THE MODERN BARBER.

LEARN.

PRACTICE.

PROVE.

MASTER THE CRAFT.

Do not make the typography playful or overly rounded.

==================================================

BACKGROUND

==================================================

The website background should be predominantly black.

However, avoid making it look flat.

Use extremely subtle layers:

- black-to-charcoal gradients

- radial light

- soft silver atmospheric glow

- subtle film grain

- very subtle noise

- blurred chrome reflections

- soft light falloff

These effects should be almost invisible until the user notices them.

The visual philosophy is:

BLACK SPACE + LIGHT + CHROME.

==================================================

HERO VISUAL

==================================================

The homepage hero should be cinematic.

Use the AURA logo prominently but elegantly.

Do NOT simply place the logo as a static image.

Create a premium entrance animation:

1. Black screen.

2. Very subtle ambient light appears.

3. Chrome reflections slowly move across the screen.

4. The AURA emblem emerges from darkness.

5. Metallic highlights travel across the emblem.

6. The AURA wordmark fades/reveals underneath.

7. The headline appears with a subtle stagger.

8. CTA buttons appear last.

The animation should be slow, elegant and cinematic.

Think:

LUXURY AUTOMOTIVE COMMERCIAL

+

HIGH-END WATCH BRAND

+

FUTURISTIC TECHNOLOGY

Not a gaming website.

==================================================

CHROME LIGHTING

==================================================

Use dynamic lighting effects around selected chrome elements.

For example:

A thin silver line can have a moving highlight passing across it.

Buttons can have a subtle reflective sweep on hover.

The logo can have a slow metallic light sweep.

Cards can reveal a soft radial spotlight when hovered.

Keep these effects extremely subtle.

==================================================

HOVER SYSTEM

==================================================

Every important interactive element should have a sophisticated hover state.

BUTTONS:

Default:

dark surface + thin silver border.

Hover:

slightly brighter chrome border,

subtle silver glow,

1-2px upward movement,

soft reflective highlight.

ACTIVE:

bright silver accent line.

CARDS:

Default:

dark black surface.

Hover:

translateY(-4px),

slightly brighter border,

subtle radial chrome illumination,

image scale 1.02-1.04.

Do NOT use colorful hover effects.

==================================================

PARALLAX

==================================================

Use elegant parallax throughout the marketing website.

Hero:

- logo moves at one speed

- typography moves at another

- background atmosphere moves slower

- cinematic image has depth

Method section:

Each step can exist on a different visual depth layer.

Case studies:

Images move subtly against the surrounding frame.

Large typography can move slightly during scroll.

Use Framer Motion and transform-based animations.

Keep motion smooth and premium.

Respect prefers-reduced-motion.

==================================================

SIGNATURE AURA EFFECT

==================================================

Create a subtle visual effect that becomes recognizable as the AURA brand.

Think of a very soft:

CHROME LIGHT FIELD

A small area of the interface can respond to cursor movement with a subtle grayscale radial glow.

Example:

As the cursor moves over a card:

a soft circular silver/white light follows the pointer.

It should be barely visible.

This should NOT look like a gaming RGB effect.

It should feel like reflected light on polished metal.

==================================================

LOGO USAGE

==================================================

The uploaded logo is the primary brand asset.

Use the exact logo without redesigning it.

Do not distort it.

Do not recolor it into green, gold, blue or purple.

Keep the chrome/silver appearance.

Use it:

- navbar

- hero

- login

- loading screen

- authentication

- certification

- footer

- favicon where appropriate

The logo should be especially prominent during the initial website loading experience.

==================================================

LOADING EXPERIENCE

==================================================

Create an exceptionally beautiful AURA loading sequence.

Black background.

Centered chrome AURA emblem.

The emblem begins almost invisible.

A subtle light passes over the chrome surface.

The emblem gradually becomes visible.

A thin silver circular line can slowly draw around it.

Then:

AURA

appears below.

After the loading sequence:

the logo subtly scales down and transitions into the navbar.

The transition into the homepage should feel seamless.

Avoid generic spinners.

==================================================

NAVIGATION

==================================================

Navbar:

black / transparent.

Initially overlay the hero.

On scroll:

background becomes slightly darker,

subtle blur,

thin silver border.

Logo on the left.

Navigation centered/right.

CTA:

START LEARNING

CTA should use black + silver/chrome only.

==================================================

CTA DESIGN

==================================================

Primary CTA:

dark black background

chrome/silver border

white text

On hover:

subtle metallic highlight sweeps across the button.

Secondary CTA:

transparent

white/silver text

minimal border.

Avoid bright filled colors.

==================================================

PROGRESS UI

==================================================

Progress should use grayscale/chrome.

Example:

0%:

dark gunmetal

50%:

silver

100%:

bright chrome/white

Verified:

silver-white glow.

Do not use green for successful/verified states.

Instead use a refined silver/chrome success state.

Errors and warnings can still use conventional semantic colors when necessary, but brand UI must remain monochromatic.

==================================================

SKILL TREE

==================================================

The Skill Tree should be one of the visual signatures of the application.

Black background.

Thin metallic silver connections.

Nodes use dark gunmetal surfaces.

Active nodes:

silver border.

Verified nodes:

bright chrome ring + subtle glow.

Locked nodes:

dark gray.

When a skill becomes verified:

animate the connection line,

then illuminate the node,

then reveal the VERIFIED state.

Make it feel like a sophisticated professional competency map.

NOT like a video game skill tree.

==================================================

CERTIFICATION

==================================================

Certification should feel extremely prestigious.

Use:

black

chrome

silver

white

Create a certificate interface inspired by:

luxury credentials

premium watch certificates

automotive certification

high-end fashion houses

Use subtle metallic borders and embossed-style effects.

A certificate verification ID should look highly official.

==================================================

IMAGERY

==================================================

Photography should match the brand:

high contrast

dramatic shadows

black backgrounds

directional lighting

close-up details

hair texture

hands

tools

precision

craftsmanship

Avoid generic smiling classroom stock photography.

Avoid colorful barber-shop imagery.

Use cinematic monochrome or desaturated imagery whenever possible.

If color photography is used, keep it dark and restrained.

==================================================

OVERALL EXPERIENCE

==================================================

The final website must feel like:

A LUXURY BARBER ACADEMY

+

A FUTURISTIC PROFESSIONAL PLATFORM

+

A PREMIUM TECHNOLOGY PRODUCT.

a traditional barber school,

or a template website.

The AURA identity should be immediately recognizable from:

BLACK

CHROME

WHITE

LIGHT

WHEN IN DOUBT, REMOVE ELEMENTS.
